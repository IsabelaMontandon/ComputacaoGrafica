HELICÓPTERO - TRANSFORMAÇÕES GEOMÉTRICAS 3D

Como executar:
1. Extraia o arquivo ZIP.
2. Abra a pasta helicoptero_transformacoes_3d.
3. Abra o arquivo index.html no navegador.
4. Use as setas do teclado para mover o helicóptero.

Controles:
- ↑ sobe
- ↓ desce
- ← esquerda
- → direita

As hélices superior e traseira giram continuamente durante a movimentação.
