# Math Plane

Math Plane é o projeto final da disciplina de Computação Gráfica da UNIFESP. A proposta é criar um jogo educativo para crianças, em que o jogador pilota um avião e escolhe balões com números para alcançar o resultado indicado na tela.

O jogo está planejado em quatro ilhas, uma para cada estação e operação matemática: verão (soma), outono (multiplicação), inverno (subtração) e primavera (divisão).

## Tecnologias utilizadas

- **HTML:** estrutura da página e elemento `canvas`, onde a cena é desenhada.
- **CSS:** estilo e organização da interface.
- **JavaScript:** construção da cena e aplicação das transformações aos objetos.
- **WebGL puro:** renderização dos modelos 3D no navegador, sem bibliotecas gráficas externas.

## Como executar

Baixe ou clone o repositório e abra `MathPlane/projeto/index.html` em um navegador com suporte a WebGL.
