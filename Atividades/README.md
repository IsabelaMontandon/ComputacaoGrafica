# Atividades de Computação Gráfica

Esta pasta reúne os exercícios desenvolvidos durante a disciplina de Computação Gráfica da UNIFESP.

| Atividade | Descrição |
| --- | --- |
| [Animação com POO](Animacao_POO/) | Modelagem e animação de um robô composto por partes. |
| [Exercícios de Bresenham](Exercicios_Bresenham/) | Exercícios de rasterização de retas, com uma aplicação no desenho de triângulos. |
| [Helicóptero e transformações 3D](helicoptero_transformacoes_3d/) | Cena com um helicóptero que demonstra movimento e rotação das hélices. |
| [Pong](Pong_Completo/) | Implementação do jogo Pong, com movimento da bola e das raquetes e detecção de colisões. |

Para executar uma atividade, abra o arquivo `index.html` correspondente em um navegador. Os exercícios de Bresenham têm um `index.html` em cada subpasta.

O projeto final da disciplina está na pasta [MathPlane](../MathPlane/).
