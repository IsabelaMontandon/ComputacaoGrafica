# Computação Gráfica

Repositório da disciplina de Computação Gráfica da UNIFESP. Aqui estão os exercícios desenvolvidos ao longo das aulas e o Math Plane, projeto final da disciplina.

## O que tem no repositório

- [**Atividades**](Atividades/): exercícios de rasterização com Bresenham, animação de um robô, transformações 3D em um helicóptero e implementação do Pong. Cada exercício tem instruções para executar e testar o código.
- [**Math Plane**](MathPlane/): projeto de um jogo educativo em que o jogador pilota um avião e escolhe balões para resolver desafios de matemática. A pasta reúne o código-fonte e os registros das entregas.

## Tecnologias utilizadas

Os exercícios e o projeto usam **HTML, CSS e JavaScript**. O robô é desenhado com **Canvas 2D**, enquanto os exercícios de Bresenham, Pong, helicóptero e o Math Plane usam **WebGL**.

## Como executar

Baixe ou clone o repositório e abra o arquivo `index.html` da atividade ou do projeto no navegador. Para o Math Plane, abra `MathPlane/projeto/index.html`. Consulte o README de cada pasta para ver os controles e o comportamento esperado.
